classDomainPrimitivesInstrumentationstatic
The metrics and trace events of domain primitives, which the generated Create and TryCreate record. Nothing is recorded until a listener subscribes: AddLaunchPadPrimitivesInstrumentation() on OpenTelemetry's meter and tracer provider builders, which the Primitives generator writes when the application references OpenTelemetry, or a Metrics.MeterListener / Diagnostics.ActivityListener of DomainPrimitivesInstrumentation.Name.
Rocket.Surgery.LaunchPad.Primitives.Registries (2)
classIso3166Countriesstatic
The 249 officially assigned ISO 3166-1 alpha-2 codes (the list Debian iso-codes publishes from the ISO 3166 Maintenance Agency). User-assigned codes (such as XK), exceptionally reserved codes (such as UK and EU) and withdrawn codes are not in it. Update it when the agency publishes a newsletter that adds or withdraws a code.
classIso4217Currenciesstatic
The alphabetic codes of ISO 4217 list one (current currency and funds codes), as published by SIX, the ISO 4217 maintenance agency, on 2026-09-17 (https://www.six-group.com/en/products-services/financial-information/data-standards.html). Update it from list-one.xml when the agency publishes an amendment.
