## Remarks

The time zone provider is resolved when the options are first built, so it does not matter whether it is registered before or after this joint. The [TimeJoint](/LaunchPad/pr-preview/pr-3295/api/rocket.surgery.launchpad.nodatime/timejoint.md) registers the provider an application uses by default.
