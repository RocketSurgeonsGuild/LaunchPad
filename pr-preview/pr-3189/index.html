One line to opt in

Name the LaunchPad SDK next to your project’s SDK. It finds the host model and adds the LaunchPad and Dovetail packages that fit.

Wiring as Joints

Health checks, logging, telemetry, validation and time are Joints that Dovetail resolves at build time. No reflection, trimming and Native AOT safe.

Reference it, get it

Referencing NodaTime, FluentValidation, HotChocolate or a Serilog sink is enough: the matching integration packages and templates come with it.
